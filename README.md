# Файлы для итогового задания

Проект создан для предоставления API на создание TODO списка с возможностью создания задач, получения списка задач по дата, периодического повторения задач, завершения и удаления задач.

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Список выполненных заданий со звездочкой:
    1. Реализована возможность определять извне порт при запуске сервера. Если существует переменная окружения TODO_PORT, сервер при старте должен слушать порт со значением этой переменной. 
    2. Реализована возможность определять путь к файлу базы данных через переменную окружения. Для этого сервер должен получать значение переменной окружения TODO_DBFILE и использовать его в качестве пути к базе данных, если это не пустая строка.
    3. Реализовано вычисление следующих дат для недель и месяцев.
    4. Реализован поиск задач через поле поиска на фронтенде. Также там можно искать задачи по дате, если ввести туда дату в формате 02.01.2006
    5. Реализована аутентификация, пароль должен лежать в .env файле в переменной TODO_PASSWORD.


Как запускать проект:

    1. Можно запустить проект с .env файлом, можно и без него, тогда аутентификация работать не будет и дефолтный порт будет 7540, пример содержимого .env файла: 
        TODO_PORT = "7540"
        TODO_DBFILE = "scheduler.db"
        TODO_PASSWORD = "Qwer12345"

    2. По умолчанию в браузере следует указывать адрес localhost:7540, если не указан иной в .env файле в переменной TODO_PORT
